# Точка перехода — лендинг

Статический сайт без сборки.

| Файл | Назначение |
| --- | --- |
| `index.html`, `style.css`, `script.js` | Лендинг |
| `oferta.html`, `privacy.html`, `consent.html`, `mailing-consent.html` | Юридические страницы (шаблоны) |
| `404.html` | Страница «не найдено», GitHub Pages подхватывает её сам |
| `favicon.svg`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `site.webmanifest` | Иконки для вкладки, iPhone и Android |
| `og-image.png` | Превью ссылки в Telegram, VK, WhatsApp, Instagram (1200×630) |
| `robots.txt` | Разрешает индексацию |

## Публикация на GitHub Pages (5 минут)

1. Создайте на GitHub публичный репозиторий `tochka-perehoda`.
2. Загрузите все файлы этой папки в корень репозитория (Add file → Upload files → Commit).
3. Settings → Pages → Source: **Deploy from a branch**, Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/tochka-perehoda/`.

Юридические страницы будут доступны как `/oferta`, `/privacy`, `/consent`, `/mailing-consent` (GitHub Pages отдаёт `oferta.html` и по адресу без расширения).

Свой домен: Settings → Pages → Custom domain, затем у регистратора CNAME на `<ваш-логин>.github.io`. В коде домен нигде не прописан.

## Что заполнить

Все места помечены `[ЗАПОЛНИТЬ: ...]`. Поиск по этой строке найдёт каждое.

| Где | Что |
| --- | --- |
| `script.js`, строка 4 | Ссылка на Telegram. Одна строка, все кнопки сайта берут её отсюда |
| `index.html`, FAQ | Платформа для видеосвязи; способы оплаты в евро |
| `img/` | Проверить права на фото из галереи до запуска рекламы. На `mood-key.jpg`, `mood-sculpture.jpg`, `mood-door.jpg`, `mood-room.jpg` есть чужие бренды и надписи (в том числе «therapy») |
| `index.html`, футер | Реквизиты ИП; ссылки на Instagram, YouTube, VK |
| `index.html`, `<head>` | Раскомментировать блок `og:image` и подставить адрес сайта. Без этого превью ссылки будет без картинки |
| `index.html`, JSON-LD FAQ | После заполнения платформы и оплаты добавить эти два вопроса в разметку |
| `robots.txt` | Строка `Sitemap` после выбора домена |
| `index.html`, блок «Отзывы» | Реальные отзывы с согласия клиентов, затем удалить атрибут `hidden` |
| `oferta.html`, `privacy.html`, `consent.html`, `mailing-consent.html` | Тексты утверждённых документов и дата редакции |

## После публикации

1. Проверить превью ссылки: отправить адрес сайта себе в Telegram (если превью старое, обновить через @WebpageBot).
2. Lighthouse: Chrome → F12 → Lighthouse → Mobile → Analyze. Цель брифа: Accessibility ≥ 90.
3. Добавить сайт в Яндекс Вебмастер и Google Search Console, отправить sitemap.
4. Поставить ссылку на сайт в профили Telegram и Instagram.

## Примечания

- Форм на сайте нет, вся конверсия идёт через Telegram, поэтому чекбоксы согласия не нужны.
- Cookie и аналитики нет. Место для подключения отмечено комментарием в `<head>`. Если аналитика будет ставить необязательные cookie, сначала нужен баннер с отказом по умолчанию.
- Для текста охрой на светлых секциях используется затемнённый оттенок `#8A5622`: исходная охра `#C17F3E` на `#F5F0E8` даёт контраст 2.9:1 и не проходит WCAG AA. На тёмном фоне используется исходная охра (5.1:1).
